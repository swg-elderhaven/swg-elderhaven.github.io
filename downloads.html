Installing and connecting

Select your existing Star Wars Galaxies installation. The launcher recognizes compatible original game data, downloads the Pre-CU files it needs, and installs Elder Haven’s updates. We recommend a separate game folder for Elder Haven.

  1. Download and open ElderHaven-Launcher.exe.
  2. Select your Star Wars Galaxies folder. The launcher repairs missing game files there. If Windows blocks writes and offers Create game copy, choose Browse to pick a writable location. A folder outside Program Files is recommended.
  3. Press INSTALL and wait for the download and verification to finish. Use UPDATE when an update is offered.
  4. Use Client Setup to choose a game resolution, use your desktop size, or enter a custom size. Select Save, then press PLAY.

The launcher configures the Elder Haven connection for you. Once PLAY is available, the client is prepared and ready to start. Open the launcher when you play so it can check for updates.

If a download is interrupted, press RETRY. The launcher keeps completed files and checks the remaining downloads automatically.

Creating your account

No separate registration is needed. Launch the game, enter your chosen username and password, and log in. Your account is created automatically the first time you connect. Existing players should use their existing account.

The server is open in alpha. You can join Discord for updates, help getting connected and bug reports.

Once you're connected, the new player guide covers your first Insight levels, buffs and missions.
