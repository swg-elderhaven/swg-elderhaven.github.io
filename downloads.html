No Elder Haven patch is needed yet. You can use a compatible Pre-CU SWG client with the connection details below.

Why are there no downloads yet?

The current Elder Haven systems run on the server and use existing client assets. Insight / Prestige, custom quest progression and combat changes do not require an Elder Haven TRE patch or a dedicated Elder Haven launcher.

A working, compatible Pre-CU Star Wars Galaxies client is still required to play. If you already have one set up, add Elder Haven to your login list.

Add Elder Haven to your login list
